# Day ↔ Night — iPhone Web App

This version is designed for an iPhone-only setup. It runs as a full-screen Home Screen web app, so no Mac, Xcode, or App Store installation is required.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload all files in this folder.
3. In the repository, open Settings → Pages.
4. Set Source to "Deploy from a branch".
5. Select the `main` branch and `/ (root)`, then Save.
6. Open the Pages URL on your iPhone in Safari.
7. Tap Share → Add to Home Screen.

## Interaction
Tap the sun/moon hotspot to switch instantly between the two artworks.

## Limitation
This is not the iOS Lock Screen itself. iOS does not allow arbitrary tap hotspots in a third-party Lock Screen wallpaper. The Home Screen web app gives the exact interaction inside a dedicated full-screen experience.
